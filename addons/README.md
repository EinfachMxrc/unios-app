# UniOS Addons

Die deklarative Addon API v1 ist in `app/addons/` implementiert. Dieser Ordner ist keine automatische Ladequelle. Ein eigenes JSON-Manifest kann unter **Mehr → Erweiterungen** importiert werden. Format, Rechte und Grenzen stehen in [docs/EXTENSIONS.md](../docs/EXTENSIONS.md).
