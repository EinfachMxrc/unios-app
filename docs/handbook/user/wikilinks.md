# Wikilinks und Rückverweise

Mit Wikilinks verbindest du Notizen über ihren Titel. Eine Notiz zeigt anschließend, welche anderen Seiten auf sie verweisen.

## Verknüpfen

Schreibe den gewünschten Titel als Wikilink in die Notiz. Die Oberfläche kann außerdem freie Titel-Erwähnungen finden und eine davon in einen Link umwandeln. Dabei entsteht eine neue Notizversion.

## Prüfen

Bei mehrdeutigen Titeln verbindet UniOS nicht automatisch. Codeblöcke und bereits vorhandene Wikilinks werden bei der Suche nach freien Erwähnungen übersprungen. Rückverweise zeigen einen Textausschnitt aus der Quelle; die Vorschau hilft, den Zusammenhang vor dem Öffnen zu verstehen. [Verhalten im Projektstand](https://github.com/EinfachMxrc/unios-app/blob/main/docs/PROGRESS.md).
