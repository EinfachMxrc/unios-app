# Dateiversionen

UniOS verändert heruntergeladene Kursdateien nicht. Neue Fassungen werden getrennt gespeichert und dem Material zugeordnet.

## Warum das wichtig ist

Wenn Lehrende eine Datei austauschen, kannst du erkennen, dass ein neuer Stand vorliegt. Markierungen aus einer älteren PDF werden anhand des ausgewählten Texts neu zugeordnet, soweit das möglich ist. Nicht zuordenbare Stellen müssen geprüft werden.

## Sicher arbeiten

Exportierte Kopien dürfen Markierungen enthalten; das gespeicherte Original bleibt unverändert. Vor einer Migration oder Wiederherstellung ist ein geprüfter Snapshot nötig. Der Reader und die Versionsübertragung haben zusätzliche [Prüfschritte mit eigenen PDFs](https://github.com/EinfachMxrc/unios-app/blob/main/docs/MANUELL_TESTEN.md).
