# Diagnose

Die CLI bietet mit uv run unios doctor eine lokale Diagnose. Sie ist ein Ausgangspunkt, wenn die App nicht erreichbar ist oder eine Verbindung nicht wie erwartet arbeitet.

## Vor dem Melden eines Fehlers

Notiere Betriebssystem, App-Version, betroffenen Ablauf und die sichtbare Fehlermeldung. Prüfe, ob ein lokaler Dienst läuft und ob der Host die Schreibrolle hat. Für Entwicklungsfälle kannst du denselben Ablauf mit der isolierten Demo nachstellen.

## Persönliche Daten schützen

Teile keine Zugangsdaten, Tokens, Session-URLs, Dateiinhalte oder Noten. Entferne solche Angaben auch aus Screenshots und Logauszügen. Bei einem vermuteten Datenproblem erst einen Snapshot prüfen, dann weitere Änderungen vornehmen. [Aktueller Projektstand](https://github.com/EinfachMxrc/unios-app/blob/main/docs/PROGRESS.md).
