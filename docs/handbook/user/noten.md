# Noten und ECTS

Noten und ECTS können in UniOS zur persönlichen Übersicht erscheinen. Die Hochschulportale bleiben die verbindliche Quelle.

## Werte kontrollieren

Vergleiche jeden importierten oder manuell erfassten Wert mit dem offiziellen Bescheid. Insbesondere bei PRIMUSS ist der Zugriff ausschließlich lesend; UniOS ändert dort keine Daten. Fehlende oder vorläufige Einträge dürfen nicht als endgültige Note ausgegeben werden.

## Persönliche Abnahme

Die Portal- und Notenabläufe benötigen Prüfung mit dem eigenen Konto. Automatisierte Tests mit Fake-Daten belegen nur die technische Verarbeitung. Nutze dafür die [manuelle Testliste](https://github.com/EinfachMxrc/unios-app/blob/main/docs/MANUELL_TESTEN.md).
