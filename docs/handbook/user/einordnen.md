# Inhalte einordnen

Der Eingang ist eine Zwischenstation. Ordne einen Eintrag einem Kurs oder Thema zu, sobald klar ist, wohin er gehört.

## Ablauf

1. Öffne den Eingang und prüfe den ursprünglichen Text, Link oder Dateinamen.
2. Wähle den passenden Kurs.
3. Speichere die Zuordnung und kontrolliere den Eintrag im Kurs.

Eine erfolgreiche Zuordnung wird kurz bestätigt; danach rückt die Liste zusammen. Bei einem Fehler bleibt der Eintrag sichtbar, damit du den Schritt wiederholen kannst.

## Später prüfen

Unklare Inhalte können zunächst im Eingang bleiben. Die Quelle und der Kontext sind wichtiger als eine schnelle, falsche Zuordnung. Für neue Datei-Uploads greift nach der Zuordnung die vorhandene Extraktion; Originaldateien werden nicht überschrieben.
