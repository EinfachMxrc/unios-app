# Was ist UniOS?

UniOS ist ein lokal betriebener Studienarbeitsplatz für Kurse, Unterlagen, Termine und Lernarbeit. Ein Gerät ist der schreibende Host; die Web-App und die CLI greifen auf seine API zu.

## Wofür es gedacht ist

Materialien bleiben beim jeweiligen Kurs. Du kannst PDFs im Reader lesen, Stellen markieren, Fragen sammeln, Notizen verknüpfen und daraus Lernarbeit ableiten. Die Tagesansicht verbindet diese Bereiche mit Aufgaben und Fristen.

## Aktueller Stand

UniOS ist eine Alpha. Kernabläufe wurden mit erfundenen Daten und lokalen Fake-Servern geprüft. Echte Hochschulportale, weitere physische Geräte und persönliche Anki-Profile brauchen eigene Abnahme. Plane vor persönlichen Daten einen geprüften Snapshot ein. [Projektstand auf GitHub](https://github.com/EinfachMxrc/unios-app/blob/main/docs/PROGRESS.md).
