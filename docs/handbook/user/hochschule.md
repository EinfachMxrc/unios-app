# Hochschule verbinden

Im Einrichtungsassistenten wählst du ein Hochschulprofil. Das Coburg-Profil ist ein Referenzprofil; ein neutrales Profil ermöglicht den Start ohne Hochschulzugang.

## Dienste einzeln prüfen

Ein Profil kombiniert Connectoren. Prüfe zuerst, welche Dienste und Berechtigungen angezeigt werden. Der Wechsel eines Profils wird nach einem Neustart aktiv. Für Moodle benötigt der eigene Account die passende Verbindung; PRIMUSS bleibt lesend.

## Anmeldung

Benutzername, Passwort und Handy-Code gehören ausschließlich in die offizielle Hochschulanmeldung. UniOS umgeht weder MFA noch CAPTCHA. Die Portalabläufe müssen mit deinem eigenen Konto anhand der [Abnahmeliste](https://github.com/EinfachMxrc/unios-app/blob/main/docs/MANUELL_TESTEN.md) geprüft werden. Leite aus einer erfolgreichen Demo keine Freigabe für ein echtes Portal ab.
