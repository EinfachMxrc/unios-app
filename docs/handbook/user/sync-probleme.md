# Sync und Material prüfen

Wenn ein Kurs oder eine Datei fehlt, beginne mit der Quelle und dem angezeigten Sync-Status. Wiederholte oder erzwungene Zugriffe auf Hochschulportale sind kein sinnvoller erster Schritt.

## Schrittweise eingrenzen

1. Prüfe, ob der richtige Host aktiv und erreichbar ist.
2. Prüfe Profil, Connector-Freigabe und den betroffenen Kurs.
3. Vergleiche die Ressource im offiziellen Portal.
4. Prüfe Gruppenfilter und Änderungszeitpunkt.
5. Nutze erst danach die lokale Diagnose.

Ein neuer Dateistand kann als zusätzliche Version vorliegen. Bei einer PDF können Markierungen zunächst in der Liste nicht zuordenbarer Stellen erscheinen. Für echte Hochschulkonten gilt die [manuelle Abnahme](https://github.com/EinfachMxrc/unios-app/blob/main/docs/MANUELL_TESTEN.md).
