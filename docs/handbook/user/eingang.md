# Inhalte sammeln

Der Eingang nimmt Dinge auf, die noch keinen festen Platz haben: spontane Gedanken, Dateien, Links und ausgeschnittene Webtexte.

## Schnell erfassen

Nutze **Smart Capture** in der App für einen Gedanken oder ein To-do. Eine kurze Sprachnotiz erscheint dort als Text, wenn dein Browser ein lokales deutsches Sprachpaket anbietet oder du das Transkript selbst ergänzt. UniOS erkennt eindeutige Aufgaben, Kursnamen und Angaben wie „bis Freitag“ lokal und legt daraus eine verknüpfte Kursaufgabe an. Ist der Kurs unklar, bleibt der Eintrag im Eingang zur Prüfung. Die Audiodatei bleibt auf deinem Gerät.

Webseiten oder markierte Textstellen kannst du über den Browserknopf beziehungsweise die Teilen-Funktion der PWA vorbefüllt öffnen. Der Server ruft die fremde Webseite dabei nicht selbst ab; er speichert den übergebenen Inhalt lokal.

## Dateien und Links

Datei-Uploads bleiben im Drop-Ordner unverändert. URL-Parameter mit sensiblen Werten werden bereinigt. Die Inhalte können lokal für die Suche indiziert werden. Prüfe vor dem Speichern, ob ein ausgeschnittener Text oder Link persönliche Daten enthält. [Aktueller Umfang](https://github.com/EinfachMxrc/unios-app/blob/main/docs/PROGRESS.md).
