# Übungen und Lernstand

Übungen verknüpfen ein Lernthema mit einer konkreten Bearbeitung. Das Ergebnis kann später helfen, die nächste Wiederholung sinnvoll zu wählen.

## Übung bearbeiten

Öffne ein Thema im Lernbereich, bearbeite die zugehörige Aufgabe und speichere deine Bewertung. Eine offene PDF-Frage kann dir zeigen, welches Konzept noch unklar ist. Kehre bei Unsicherheit zum Quellmaterial zurück.

## Auswertung

Study Cycles und Lernblöcke verdichten erfasste Arbeit. Sie ersetzen keine fachliche Bewertung und zeigen bei zu wenig Daten keine scheinbar präzise Prognose. Der persönliche Lernfluss, besonders über mehrere Geräte, gehört zur [manuellen Abnahme](https://github.com/EinfachMxrc/unios-app/blob/main/docs/MANUELL_TESTEN.md).
