# Hochschul-Login

Hochschul-Logins erfolgen auf der offiziellen Seite des jeweiligen Dienstes. UniOS umgeht weder MFA noch CAPTCHA.

## Zugangsdaten

Gib Passwort und Handy-Code nur auf der offiziellen Hochschulseite ein. Technische Secrets gehören in den OS-Schlüsselbund; eine lokale Datei mit eingeschränkten Rechten ist nur der vorgesehene Ersatzweg. Teile keine Tokens, Session-URLs oder persönlichen Noten in Issues oder Logs.

## Portalzugriff

PRIMUSS wird ausschließlich lesend verwendet. Moodle-Abgaben benötigen eine separate Bestätigung in der Oberfläche. Für den echten Account sind die [manuellen Portalprüfungen](https://github.com/EinfachMxrc/unios-app/blob/main/docs/MANUELL_TESTEN.md) maßgeblich.
