# Feature- und UI-Addons

UniOS hat eine lokale, deklarative Addon API v1. Connectoren bleiben ein eigener Vertrag für externe Datenquellen. Ein Addon-Manifest beschreibt einen Core-Ansichtstyp, einen festen Platz und die benötigten Datenrechte. Unter **Mehr → Erweiterungen** lässt es sich importieren, installieren, freigeben und aktivieren. Eigener React-, JavaScript- oder Python-Code wird nicht geladen.

Das Format, ein vollständiges Beispiel, die Slots und die Sicherheitsgrenzen stehen in [Extensions](../../EXTENSIONS.md).
