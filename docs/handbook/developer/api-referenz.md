# API-Referenz

Die folgenden Themenseiten werden beim Dokumentations-Build aus frontend/openapi.json erzeugt. Sie spiegeln die vorhandenen Pfade und Methoden wider.

## So liest du die Liste

Wähle links den Bereich, etwa Kurse und Material oder Host und Einrichtung. Jede Zeile zeigt HTTP-Methode, Pfad und die im Schema vorhandene Kurzbeschreibung. Für Request-Body, Parameter, Antwortschema und Fehlercodes öffne das [vollständige OpenAPI-Schema](https://github.com/EinfachMxrc/unios-app/blob/main/frontend/openapi.json).

## Grenzen

Die Gruppierung ist eine Lesehilfe, kein neuer API-Vertrag. Manche Endpunkte tragen im Schema noch keine fachlichen Tags; sie werden nach Pfadstamm oder unter „Weitere Endpunkte“ eingeordnet. Die Referenz beschreibt die lokale API, keine öffentliche Mehrnutzer- oder Cloud-Schnittstelle.
