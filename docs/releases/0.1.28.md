# UniOS 0.1.28 – KI-Schlüssel statt Modell-IDs, Backup mit Anki, Korrekturen

Neu: Auf der KI-Seite fügst du deinen Anthropic-API-Schlüssel ein und wählst das Modell aus der Liste, die der Anbieter für deinen Schlüssel liefert. Der Schlüssel liegt im Schlüsselbund dieses Geräts, zur Prüfung wird nur die Modellliste abgefragt.

Behoben: dauerhaft gesperrtes KI-Monatsbudget nach abgelehnten Anfragen, fehlende Anki-Sammlung im eingebauten Backup, ausgeblendete Stundenplan-Slots im KI-Kontext, unlösbare Nullstellen-Aufgaben, hängende Prüfungssperren, fehlende Browser-Berechtigung der Desktop-App. Alle Änderungen: [CHANGELOG](../../CHANGELOG.md).

## Was dieses Release enthält und was nicht

- Enthalten: vollständiger Quellcode, das Server-Quellpaket mit Prüfsumme.
- **Keine fertigen Installer.** Windows- und macOS-Pakete wurden für diese Version nicht gebaut (GitHub Actions ist für das Konto derzeit nicht nutzbar, lokal fehlt eine Windows-Umgebung). Wer die Desktop-App nutzen will, bleibt bei 0.1.27 oder baut sie nach [DESKTOP_PACKAGES](../DESKTOP_PACKAGES.md).
- Keine neue Datenbankmigration. Vor einem Update vorhandener Daten einen geprüften Snapshot erstellen ([Server](../SERVER.md)).

## Geprüft

Backend 1359 Tests bestanden (ein umgebungsbedingter Fehlschlag: lokale Signier-Identität nicht vertrauenswürdig), Frontend 1427 Tests, Typprüfung, Lint, Build, OpenAPI-Vertrag und Playwright für den KI-Ablauf gegen lokale Fake-Server. Nicht geprüft: ein echter Anthropic-Schlüssel, echte Hochschulkonten, Geräteabnahmen.
