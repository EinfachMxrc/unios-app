# UniOS 0.1.29 – Lokaler Modus ohne Server und viele Korrekturen

**Neu:** Beim ersten Start der Desktop-App kannst du „Nur auf diesem Gerät nutzen“ wählen. UniOS läuft dann mit einer lokalen Datenbank, ohne eigenen Server. Wer schon einen Server gekoppelt hat oder lokal arbeitet, behält seinen Modus. Der Wechsel zwischen lokal und Server geschieht nie automatisch, sondern nur über die geprüfte Datenübernahme ([Server und Migration](https://github.com/EinfachMxrc/unios-app/blob/main/docs/SERVER.md)).

**Außerdem neu:** Kurs-Schreibtisch und geräumigere PDF-Mitschrift.

**Behoben:**

- Backup und Migration: Anki-Sammlung wird konsistent gesichert, Restore bringt auch gleich große geänderte Dateien zurück, KI-Modellwahl und -Schlüssel gehen nicht mehr verloren.
- Kalender: ausgeblendete Stundenplan-Slots und Zeitzone gelten für Lernblöcke, Export und KI-Korpus.
- Prüfungsmodus: abgelaufene Prüfungen geben Versuche, Berichte und Hinweise frei.
- Papierkorb: gelöschte Notizen und Schnellerfassungen bleiben aus KI-Korpus, Offline-Suche und Smart-Capture heraus.
- Textindex: keine Endlosschleife mehr bei fehlgeschlagenen, leeren oder zu großen Dokumenten.
- Host: Worker und Benachrichtigungs-Job laufen nach einer Standby-Übernahme; Sync startet nach der Einrichtung ohne Neustart.
- Oberfläche: PDF-Auszüge bei geschlossenem Notiz-Drawer, Offline-Warteschlangen, Notizkarten-Dialog nach Workspace-Reset, Suchausschnitte.
- Desktop und Docker: fehlende Berechtigung der Raumprüfung, Portal-Lesemodus je Fenster, interne Links im Demo-/Wiederherstellungsmodus, `config` im lokalen Docker-Image.

**Nicht verifiziert:** Der Ablauf „Nur auf diesem Gerät nutzen“ ist per Test des Dienstes abgedeckt, der Neustart über die Desktop-Hülle aber nur auf einem installierten Gerät prüfbar ([MANUELL_TESTEN](https://github.com/EinfachMxrc/unios-app/blob/main/docs/MANUELL_TESTEN.md)). Keine Prüfung mit echten Hochschulkonten.

Vor dem Update vorhandener Daten einen Snapshot erstellen und prüfen. Diese Version bringt keine Schema-Migration mit; Originaldaten bleiben erhalten.
