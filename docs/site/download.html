Alpha 1 · 0.1.19

Dein Studium. Ein Arbeitsplatz.

Die erste UniOS-Vorabversion ist zum Ausprobieren bereit. Die Desktop-App enthält ihre Laufzeit und verbindet sich für den dauerhaften Betrieb mit deinem eigenen HTTPS-Server. Ohne Hochschulkonto kannst du die getrennte Quellcode-Demo testen.

Windows

x64 · Setup.exe oder MSI

Setup herunterladen → Bestehende Windows-Installation geprüft. Frische Geräteabnahme und öffentliches Code-Signing stehen aus.

macOS

Apple Silicon · DMG

DMG herunterladen → CI-Build bestanden. Ad-hoc-Signatur, keine Developer-ID/Notarisierung. Intel-Paket derzeit durch eine Abhängigkeit blockiert.

Linux

x64 · DEB oder AppImage

Linux-Pakete im Release → CI-Build bestanden. Die vollständige Bedien-/Installationsprüfung auf frischen Linux-Desktops steht aus.

Was diese Alpha bedeutet

Vorabversion mit offenen Geräte- und Hochschulprüfungen. Automatische Updates sind deaktiviert; vor einem Update eines vorhandenen Datenbestands einen Snapshot erstellen und prüfen.

Release-Hinweise und SHA-256-Prüfsummen · Installation und Demo · Server einrichten

Das Repository ist derzeit privat. Release und Downloads benötigen einen berechtigten GitHub-Zugang. Diese Projektseite wird dadurch nicht automatisch öffentlich gehostet.
